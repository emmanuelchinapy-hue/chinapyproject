# CHINAPY EMMANUEL Scholarship Application

A responsive, frontend-only application form for the CHINAPY EMMANUEL International Student Scholarship. Open `index.html` in a browser, or serve this directory with any static web server.

The searchable school suggestions in `app.js` are a curated, non-exhaustive selection of Nigerian institutions. Applicants whose institution is not included can choose **Other (not listed)** and enter its name.

The form checks required details, institution selection, programme-year order, and school ID file type and size (PDF, JPG, or PNG up to 5 MB). Submission presents an on-page application preview; it does not transmit or save any form data or uploaded files. Connect a backend before using the form to collect applications.
